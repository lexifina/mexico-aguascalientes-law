ARTICULO 400.- La Contraloría Municipal vigilará el cumplimiento de las disposiciones a que se refiere este Código y queda facultada para interpretar el mismo para efectos administrativos, así como para dictar las disposiciones que se requieran para su adecuada aplicación y cumplimiento.
